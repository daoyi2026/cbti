# Project maintenance

- Resolve file paths from one explicit project root. When a command runs in this checkout, do not prefix its paths with the parent workspace path again.
- Preserve supplied source GLBs and reviewed asset versions outside this checkout. Commit only the selected runtime models, each below 10 MB, and update the hash manifest.
- Verify every provided model visually before assigning a character identity; file order and opaque filenames do not identify a breed.
- Keep looped ear/blink animation independent of triggered gestures. Review animation contact sheets and contact points before accepting a rig.
- Re-enumerate all answer combinations after persona or affinity changes. Standard outcomes should stay balanced, while hidden outcomes follow their documented eligibility and target share.
- Label sample cards explicitly and keep them distinct from scored results. Verify fresh attempts, repeated attempts, and answer editing after changing quiz entry points.
